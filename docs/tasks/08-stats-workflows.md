# P2 · 统计推断工作流（比例 / 组间 / 相关 / 分类结局）

## 目标

不是再堆菜单，而是按标志物分析把「该用什么检验」做成向导 + 方法说明。复杂模型从单组、单因素到多因素逐步升级。

## 1. 比例分析

文档认为类型太多、制图逻辑未收敛，需要按文章常用逻辑归纳。

### 建议收敛成 3 步（可做成一个模块）

1. **阳性率 / Ratio**：每个样本、每种细胞占总细胞或指定集合的比例（如 CD8 / (CD8+Foxp3+CD68)）
2. **组中位数表**：按 Group（预后、性别、病理分型）对每个细胞类型取中位数（不用均值），得到中位数比率表
3. **展示与检验**
   - 堆叠柱状：X=Group，Y=Ratio，填充=CellType
   - 组间差异：两组 Mann-Whitney；≥3 组 Kruskal-Wallis（比例通常偏态）
   - 配 Box Plot（原始样本比率，不是中位数表）

### 子任务

- [ ] **T-08-01** 数据面板「比率计算」：分子/分母多选，生成 Ratio 列（文档曾问是否要单独面板，建议放清洗/转换区）
- [ ] **T-08-02** 「组中位数汇总」：分组变量 × 多个 Ratio → 新表（可另存或输出到结果）
- [ ] **T-08-03** 堆叠柱状模板（中位数表）
- [ ] **T-08-04** 比例组间比较默认非参数，方法说明写清为什么不用均值
- [ ] **T-08-05** 出一页「比例分析常用逻辑」说明（总量 vs 亚组、哪些图配哪些表）

## 2. 组间比较向导

按文档决策树自动建议模型，允许用户覆盖。

```
因变量连续？
  ├ 独立样本
  │   ├ 2 组：正态+方差齐 → t；正态不齐 → Welch；非正态 → Mann-Whitney
  │   └ ≥3 组：正态+齐 → ANOVA；正态不齐 → Welch ANOVA；非正态 → Kruskal-Wallis
  ├ 配对 / 癌-癌旁 / 治疗前后
  │   └ 差值正态 → 配对 t；否则 Wilcoxon；分类配对 → McNemar
  ├ 重复测量（多时间点）
  │   └ 正态 → 重复测量 ANOVA；否则 Friedman
  └ 两因素 / 协变量
      └ two-way ANOVA / ANCOVA / 多元协方差
因变量分类/等级？
  ├ 理论频数 >5 → 卡方
  ├ <5 → Fisher
  └ 有序等级 → 秩和
```

### 子任务

- [ ] **T-08-06** 「组间比较」入口：选因变量、分组，先跑 Shapiro / Levene（或文档指定的齐性检验），再给出推荐并一键运行
- [ ] **T-08-07** 结果默认带发表级 Box Plot + p 值（接 [06](./06-eda-plots.md)）
- [ ] **T-08-08** 方法说明内嵌文档的「典型场景案例」（PD-L1 TPS、病理亚型等）
- [ ] **T-08-09** 多因素：two-way ANOVA 主效应+交互；ANCOVA 控制年龄/肿瘤大小等
- [ ] **T-08-10** 分类结局：二分类 / 多分类 / 有序 Logistic；OR 与 95% CI 解读写进说明

现有 jmv 已有这些检验，缺的是**向导、默认图、文案**，不要重复造统计引擎。

## 验收
