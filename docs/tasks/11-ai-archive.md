# P3 · AI 解读与总结存档

## 目标

1. **AI 解读**：对批量生成的图/表做筛选和解读，给出下一步挖掘线索，输出解读报告。  
2. **总结存档**：按项目收拢分析策略、原始数据、`.omv`（含脚本）、关键图表。

这两项都依赖 P1 批处理的目录约定和 P2 主流程已经能稳定出结果。

## AI 解读

### 范围（先做只读助手，不做自动改模型）

- 输入：`exports/{analysis}/index.csv` + 图 + 关键表
- 输出：Markdown/Word 报告
  - 哪些指标过阈值（p、HR、AUC）
  - 建议纳入多因素的变量
  - 明显异常（PH 假定失败、事件数不足、AUC≈0.5）
  - 下一步：亚组、交互、聚类验证等

### 子任务

- [ ] **T-11-01** 确定模型与数据出域策略（本地 / 私有 API）；病理数据默认不出公网
- [ ] **T-11-02** 把批处理 index 与图做成结构化 prompt（变量名、n、事件数、p、HR、AUC）
- [ ] **T-11-03** 报告模板：筛选表 + 解读 + 建议；可勾选「仅阳性结果」
- [ ] **T-11-04** 结果面板或导出目录一键「生成解读」
- [ ] **T-11-05** 人工确认后才能写入 X-Lab「关键结果」字段（见 [12](./12-xlab.md)）

不做：自动改分析选项、自动发表结论、无引用的因果表述。
