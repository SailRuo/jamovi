# P1 · 批处理

## 目标

一次对大量定量指标做同一分析，并把每个指标的图/表导出到指定文件夹。文档场景：全部指标阳性率按中位数分高低组，做单因素生存；以及描述图、组间比较。

## 现状

没有产品级批处理。一次只跑一个分析实例。结果只能整页 HTML/PDF 或单个元素导出。

文档犹豫：独立「批处理面板」还是各功能下加按钮。

## 建议方案（默认）

**不新增 Ribbon Tab。**

```
左侧：勾选要批处理的变量（尺度变量多选）
中间：分析模板（当前分析的选项，分组/时间/终点等固定）
右侧：当前预览的一个指标结果
中间底部：【批处理导出】→ 选文件夹
```

底层做一个 `BatchRunner`，EDA、组间比较、单因素 KM 共用。

独立 Tab 的问题：会和分析选项面板重复，且生存/组间选项差异大。

## 第一期范围

| 模板 | 固定部分 | 循环部分 | 输出 |
|---|---|---|---|
| 数值描述 + 直方图/箱线 | 选项 | 每个尺度变量 | 每变量一张图 + 汇总 csv |
| 组间比较 Box Plot | 分组变量、检验规则 | 每个定量指标 | 图（带 p）+ p 值总表 |
| 单因素生存 | time、status、中位数切分规则 | 每个定量指标 | KM 图 + HR/p 总表 |

第二期再考虑：单因素 Cox 批量、单因素 ROC 批量（与 [09](./09-survival-roc.md) 的 Rj 脚本合并成模块）。

## 子任务

- [ ] **T-07-01** 设计导出目录约定，例如：
  ```
  {project}/exports/{date}_{analysis}/
    index.csv          # 变量, p, HR, 文件名
    plots/{var}.png
    tables/{var}.html
  ```
- [ ] **T-07-02** server 增加批量任务：克隆分析 options、替换因变量、串行跑、写文件（注意 R 引擎队列，避免打爆 session）
- [ ] **T-07-03** 分析选项 UI 增加变量多选 +「批处理导出」按钮（先做 Descriptives 和 Box Plot）
- [ ] **T-07-04** 生存：按中位数（或指定分位数）自动二分，再 KM；切分阈值写入结果
- [ ] **T-07-05** 进行中进度条、失败变量不中断整批、index.csv 记录错误
- [ ] **T-07-06** 连续变量默认原始值；若用户选了 Z 列，警告
- [ ] **T-07-07** 大批量时不要在结果面板生成 N 个分析条目（只预览 1 个 + 磁盘输出），避免 `.omv` 膨胀/崩溃（文档已担心）

## 验收

- 选 50 个定量指标 + 预后分组，一键得到 50 张箱线图和一张 p 值总表
- 选 50 个指标 + PFS time/status，一键得到 50 张 KM 和 HR 总表
- 主 `.omv` 仍然只有模板分析，不插入 50 份结果
