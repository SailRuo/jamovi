# P1 · 数据清洗与变换

## 目标

把文档「数据清洗操作」从散落的原生步骤，收成数据面板上可完成的工具。Excel 仍负责表格合并；Jamovi/X-Stat 负责统计层预处理。

## 现状（文档原步骤，多数已能手动做）

| 需求 | 现状 | 缺口 |
|---|---|---|
| 修改变量类型 | 变量面板 | 保持 |
| 缺失识别 | 分析 → 探索 → 描述 | 保持，入口可缩短 |
| 删列（缺失>50%）/ 删行（缺失>30%） | 手动过滤 | 无批量规则工具 |
| 均值/中位数/众数填充 | 计算列公式 `IF(ISMISSING(...))` | 无向导 |
| 异常值：箱线 / \|Z\|>3 | 描述图 + 标准化后过滤 | 文档注明：转换后变量无法过滤 |
| 缩尾 / 截断 | 公式 | 无工具 |
| Z-score / log / sqrt / Box-Cox | Transform | Box-Cox 是否现成需核对 jmv |
| 分类合并 | Recode | 保持 |
| 全量复查 | 描述 | 保持 |
| jReshape | 分析面板 | 要挪到数据面板 |

## 子任务

- [ ] **T-05-01** 数据面板增加「清洗」分组：缺失、异常、标准化、正态化（不要做成独立分析 Tab）
- [ ] **T-05-02** **缺失工具**：按变量出缺失率表；勾选规则（变量缺失>50% 建议删列；样本缺失>30% 建议删行）；一键生成过滤或删除
- [ ] **T-05-03** **填充向导**：选变量 → 均值/中位数/众数 → 生成新列（保留原列），不要覆盖
- [ ] **T-05-04** **异常值工具**：IQR 箱线离群 + \|Z\|>3 列表；处理：删除 / 缩尾（指定 min/max）/ 转新列
- [ ] **T-05-05** 修复「Z-score 后无法过滤」：过滤表达式识别变换列，或清洗工具直接写 filter
- [ ] **T-05-06** **标准化**：多变量批量 Z-score，新列后缀可配置（文档常用 ` - z`）
- [ ] **T-05-07** **正态化**：Shapiro-Wilk 一览；提供 ln / log10 / sqrt / Box-Cox（λ 自动）；新列 + 再检验
- [ ] **T-05-08** 连续变量作图一律用原始值的提示（方法说明 + 清洗向导警告）
- [ ] **T-05-09** jReshape 入口见 [04-modules.md](./04-modules.md)；方法说明写明「应急，灵活度不及 Excel」
- [ ] **T-05-10** 生存终点变量检查：时间>0 数值、status 必须是 0/1 连续而非因子标签（文档踩过的坑）

建议形态：优先「数据面板向导 + 生成计算列/过滤」，而不是让用户记公式。底层可复用 `client/main/editors/transformeditor.ts`、`filterwidget.ts`、`server/jamovi/server/compute/`。

## 验收

- 对一张含缺失和偏态的定量病理表，不写公式即可：删高缺失、中位数填充、Z-score、缩尾
- 填充/变换都生成新列，原列仍在
- \|Z\|>3 的行能被过滤掉
- 生存 time/status 不合规时，进入 KM/Cox 前就能报错

[04-modules.md](./04-modules.md) 的数据面板入口。Box-Cox 若 jmv 没有，需新 R 模块。
