# P2 · 聚类分析（热图 + 临床注释）

## 目标

补上文档缺口：现在只能做基础聚类和热图，**不能叠加临床变量注释条**。完整路径是：标准化 → 层次聚类 → 热图+临床条 → 最优 K → 与临床列联表 → KM/Cox 验证 → 可选 ROC 预测疗效。

## 现状

- 计划用 **snowCluster**：Hierarchical（主）、K-means、可选 DBSCAN
- 可视化子模块（独立 Dendrogram / MDS / PCA plot）文档标了「舍弃？」——默认 **P2 不做独立可视化包**，热图自带树状图即可
- 临床注释条、ORR/TPS/病理亚型色带需要改模块或新写 pheatmap/ComplexHeatmap 封装

## 分析策略（写入方法说明）

1. 预处理：Z-score；去掉无临床终点的样本；只留有生物学意义的标志物  
2. 层次聚类：距离 euclidean，方法 ward.D2  
3. 最优 K：树高度差 / 肘部 / 轮廓系数（K-means 辅助）  
4. Save cluster number 为新变量  
5. 列联表：Cluster × 病理/性别/分期/PD-L1 分级  
6. KM + Log-rank；单因素 Cox（p<0.1 进多因素）；多因素 Cox 看独立预后  
7. 可选：Cluster vs PD-L1 预测 ORR 的 ROC（AUC 解读 0.5 / 0.7 / 0.9）

## 子任务

- [ ] **T-10-01** 层次聚类热图：行=标志物，列=样本，颜色为 Z-score
- [ ] **T-10-02** **顶部临床注释条**：多条分类/有序变量（ORR、PD-L1 TPS、病理亚型、原发/转移等），带图例
- [ ] **T-10-03** 行、列树状图；可按列聚类截断着色
- [ ] **T-10-04** 参数默认 euclidean + ward.D2；可选 Pearson 距离
- [ ] **T-10-05** 保存 Cluster 到数据集
- [ ] **T-10-06** K-means：大样本或客观分层；输出肘部图，建议 K
- [ ] **T-10-07** DBSCAN：标为高级，用于离群/罕见亚型，不作为默认
- [ ] **T-10-08** 「聚类验证」一键：列联表 + KM（接生存模块）参数预填 Cluster
- [ ] **T-10-09** 方法说明含论文表述模板（文档已有示例段）
- [ ] **T-10-10** 独立 MDS/PCA 图：默认不做；若销售需要再开任务

## 验收

- 一张免疫标志物矩阵 + 若干临床列，能出带注释条的热图
- Cluster 写回后可直接做 KM，无需手工复制分组
- 与「只能出裸热图」的现状有明显差异
