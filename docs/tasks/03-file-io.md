# P0 · 数据替换与导出拆分

## 目标

1. 「特殊导入」更名为「数据替换」，从项目菜单挪到**数据面板**。场景：套用分析模板，导入列名一致的新数据，刷新全部预置结果。
2. 导出拆成两项，语义分开：
   - **导出原始数据**：当前表格所见状态 → csv（及必要的 xlsx）
   - **导出结果**：分析结果图和文字描述

## 现状

文档评价：Jamovi 原生导出逻辑不清。当前 File → Export 把数据格式（csv/xlsx/sav/…）和结果格式（pdf/html/latex）混在一个列表里。

| 能力 | 位置 |
|---|---|
| Special Import | `client/main/backstage.ts` `createOps()` `name: 'import'` |
| 混合 Export | 同上 `name: 'export'` |
| 整份结果 HTML/PDF | `server/jamovi/server/instance.py` `_on_save_content` |
| 单个结果图/表 | `client/main/resultspanel.ts` 右键 Export |
| 数据写盘 | `server/jamovi/server/formatio/` |

「特殊导入」本身就是：在保留分析的前提下替换数据集。改名 + 换入口即可覆盖模板场景，但要验证列名不一致时的行为并给出明确提示。

## 子任务

### 数据替换

- [ ] **T-03-01** 从 Backstage ops 移除 `import`
- [ ] **T-03-02** 数据面板增加「数据替换」大按钮（`client/main/ribbon/datatab.ts`）
- [ ] **T-03-03** 复用现有 import 流程；完成后刷新分析
- [ ] **T-03-04** 列名/类型不匹配时给出对照报告（新增/缺失/类型变化），不要静默错位
- [ ] **T-03-05** 方法说明中写清：适合「模板 `.omv` + 同结构新队列」

### 导出拆分

- [ ] **T-03-06** 项目菜单改为两个入口：`导出数据`、`导出结果`
- [ ] **T-03-07** 导出数据：默认 csv，可选 xlsx；导出的是加工后的当前表（含计算列、过滤后可见行需产品确认，见 [99](./99-open-questions.md)）
- [ ] **T-03-08** 导出结果：pdf / html；默认带注释与引用
- [ ] **T-03-09** 结果面板单个图/表导出保留，文案与「导出结果」一致
- [ ] **T-03-10** 批处理导出目录结构预留（见 [07-batch.md](./07-batch.md)），本任务只做单次导出

## 验收

- 项目菜单不再出现「特殊导入」和含糊的「导出」
- 用模板 `.omv` + 同列名 csv 替换后，原分析全部重跑出结果
- 列名缺失时有明确错误，数据不被错列覆盖
- 「导出数据」得到可打开的表；「导出结果」得到图+文字，不含原始大表（除非用户另选）
